# 第 3 章　分支与循环 ／ 第3章　分岐とループ

## 本章目标 ／ 本章の目標
掌握 `if / else if / else` 做条件判断，掌握 `for` 和 `while` 做重复执行；能根据场景判断该用哪种循环。

> 🇯🇵 `if / else if / else` による条件判断と、`for` および `while` による繰り返し処理を習得します。場面に応じてどちらのループを使うべきか判断できるようになります。

## 一句话理解 ／ 一言で理解する
分支是"根据条件走不同的路"，循环是"把同一段代码反复执行很多遍"——它们是程序具备"判断力"和"耐力"的开始。

> 🇯🇵 分岐は「条件によって異なる道を進む」こと、ループは「同じコードを何度も繰り返し実行する」ことです——これらはプログラムが「判断力」と「持久力」を持つ第一歩です。

## 为什么需要它 ／ なぜ必要なのか
如果程序只能从上到下顺序执行，那它顶多算个计算器：算一次就完事。而现实业务几乎都需要"判断"（比如成绩及格还是不及格）和"重复"（比如把 100 个用户的信息都打印一遍）。有了分支和循环，程序才第一次具备处理"真实业务逻辑"的能力。

> 🇯🇵 プログラムが上から下へ順番に実行されるだけなら、せいぜい電卓のようなもので、1回計算したら終わりです。しかし現実の業務では、ほぼ必ず「判断」（例えば成績が合格か不合格か）と「繰り返し」（例えば100人分のユーザー情報を全部出力する）が必要になります。分岐とループがあって初めて、プログラムは「実際の業務ロジック」を処理する能力を持つのです。

## 核心概念 ／ コアコンセプト

### 3.1 分支：if / else if / else ／ 分岐：if / else if / else

```
if (条件1) {
    // 条件1 成立时执行
} else if (条件2) {
    // 条件1 不成立、条件2 成立时执行
} else {
    // 前面条件都不成立时执行
}
```

- 条件必须是一个 `boolean` 表达式（结果是 `true` 或 `false`），不能像某些语言那样直接写 `if (1)`。<br><span class="ja-inline">🇯🇵 条件は必ず `boolean` 式（結果が `true` または `false`）でなければならず、一部の言語のように `if (1)` と直接書くことはできません。</span>
- `else if` 可以写多个，`else` 最多一个且必须放最后，也可以不写 `else`。<br><span class="ja-inline">🇯🇵 `else if` は複数書くことができますが、`else` は最大1つで、必ず最後に置きます。`else` を書かなくても構いません。</span>
- 分支是"从上到下，命中一个就跳出，后面的都不再判断"。<br><span class="ja-inline">🇯🇵 分岐は「上から下へ判定し、1つに合致したら抜け出し、以降は判定しない」という仕組みです。</span>

### 3.2 循环：for 和 while ／ ループ：for と while

`for` 循环，语法上把"初始化、判断条件、每轮之后的动作"写在一行里：

> 🇯🇵 `for` ループは、文法上「初期化・条件判定・毎回の後処理」を1行にまとめて書きます。

```
for (初始化; 条件; 每轮结束后执行) {
    // 循环体
}
```

`while` 循环，只关心"条件为真就继续"：

> 🇯🇵 `while` ループは「条件が真である限り続ける」ことだけに注目します。

```
while (条件) {
    // 循环体
}
```

还有一种 `do-while`，特点是"先执行一次，再判断要不要继续"，本教程后面不常用，这里只作了解：

> 🇯🇵 もう1つ `do-while` というものもあり、「まず1回実行してから、続けるかどうかを判定する」のが特徴です。本チュートリアルでは以降あまり使わないため、ここでは概要だけ紹介します。

```
do {
    // 至少执行一次
} while (条件);
```

### 3.3 到底该用 for 还是 while？ ／ 結局 for と while のどちらを使うべきか

一句话判断标准：**明确知道要循环几次（或者有一个明显的计数器），用 `for`；只知道"满足某个条件就继续，不知道具体几次"，用 `while`。**

> 🇯🇵 一言でいう判断基準は次の通りです。**ループの回数が明確にわかっている（または明らかなカウンタがある）場合は `for` を使い、「ある条件を満たしている限り続ける」だけで具体的な回数がわからない場合は `while` を使います。**

| 场景 ／ 場面 | 特点 ／ 特徴 | 该用 ／ 使うべきもの |
|---|---|---|
| 打印 1 到 100<br><span class="ja-inline">🇯🇵 1から100まで出力する </span>| 次数从一开始就是确定的（100 次）<br><span class="ja-inline">🇯🇵 回数が最初から確定している（100回） </span>| `for` |
| 遍历数组/集合里的每个元素<br><span class="ja-inline">🇯🇵 配列やコレクションの各要素を巡回する </span>| 元素个数是确定的<br><span class="ja-inline">🇯🇵 要素数が確定している </span>| `for` |
| 倒计时"从 10 数到发射"<br><span class="ja-inline">🇯🇵 「10から発射までカウントダウン」する </span>| 每次减 1，直到某个值，条件驱动更自然<br><span class="ja-inline">🇯🇵 毎回1ずつ減り、ある値になるまで続く。条件駆動の方が自然 </span>| `for` 或 `while` 都可以，这里两种都演示<br><span class="ja-inline">🇯🇵 `for` でも `while` でもよく、ここでは両方とも示す </span>|
| 反复读取用户输入，直到用户输入"退出"<br><span class="ja-inline">🇯🇵 ユーザーが「終了」と入力するまで、繰り返し入力を受け取る </span>| 不知道用户会输入几次<br><span class="ja-inline">🇯🇵 ユーザーが何回入力するかわからない </span>| `while` |
| 库存不断被扣减，直到库存为 0<br><span class="ja-inline">🇯🇵 在庫が減り続け、0になるまで続く </span>| 每轮扣减的数量可能不固定，次数不确定<br><span class="ja-inline">🇯🇵 毎回減る数量が一定でない場合があり、回数が不確定 </span>| `while` |

记住这个经验规则就够用了：**次数确定用 for，条件不确定用 while**。两者本质上可以互相改写，选择哪个只是让代码读起来更自然。

> 🇯🇵 この経験則さえ覚えておけば十分です。**回数が確定していれば for、条件が不確定なら while を使う。**両者は本質的に互いに書き換え可能で、どちらを選ぶかはコードをより自然に読ませるためのものです。

## 最小示例 ／ 最小限のサンプル

### 示例一：成绩判定（分支） ／ 例1：成績判定（分岐）

`GradeDemo.java`
```java
public class GradeDemo {
    public static void main(String[] args) {
        int score = 78;
        String grade;

        if (score >= 90) {
            grade = "优秀";
        } else if (score >= 75) {
            grade = "良好";
        } else if (score >= 60) {
            grade = "及格";
        } else {
            grade = "不及格";
        }

        System.out.println("分数：" + score + "，等级：" + grade);
    }
}
```

### 示例二：倒计时（for 和 while 两种写法对比） ／ 例2：カウントダウン（for と while の書き方の比較）

`CountdownDemo.java`
```java
public class CountdownDemo {
    public static void main(String[] args) {
        // 写法一：用 for，因为"从 5 数到 1"次数是确定的
        System.out.println("---- for 版本 ----");
        for (int i = 5; i >= 1; i--) {
            System.out.println(i);
        }
        System.out.println("发射！");

        // 写法二：用 while，效果完全一样，只是换了一种表达方式
        System.out.println("---- while 版本 ----");
        int count = 5;
        while (count >= 1) {
            System.out.println(count);
            count--;
        }
        System.out.println("发射！");
    }
}
```

## 代码逐行解释 ／ コードの行ごとの解説

**示例一（GradeDemo）**
> 🇯🇵 **例1（GradeDemo）**

- `if (score >= 90)`：先判断是否达到"优秀"的门槛。<br><span class="ja-inline">🇯🇵 `if (score >= 90)`：まず「優秀」の基準に達しているかを判定します。</span>
- `else if (score >= 75)`：只有在第一条不成立时才会走到这里判断——所以这里不需要再写 `score < 90 && score >= 75`，因为能走到这一步就已经说明 `score < 90` 了。<br><span class="ja-inline">🇯🇵 `else if (score >= 75)`：最初の条件が成立しない場合にのみここに到達して判定されます——そのため `score < 90 && score >= 75` と改めて書く必要はありません。ここに到達した時点で既に `score < 90` であることが分かっているからです。</span>
- `else if (score >= 60)`：同理，只需要判断下限。<br><span class="ja-inline">🇯🇵 `else if (score >= 60)`：同様に、下限だけを判定すればよいのです。</span>
- `else`：前面所有条件都不满足，兜底为"不及格"。<br><span class="ja-inline">🇯🇵 `else`：それまでの条件がすべて満たされなかった場合の受け皿として「不合格」となります。</span>
- 这里体现了一个重要习惯：**多个区间判断时，从高到低（或从低到高）依次排列，配合 `else if`，避免逻辑重复和遗漏**。<br><span class="ja-inline">🇯🇵 ここには重要な習慣が表れています。**複数の区間を判定する際は、高い方から低い方へ（またはその逆に）順に並べ、`else if` と組み合わせることで、ロジックの重複や漏れを防ぎます。**</span>

**示例二（CountdownDemo）**
> 🇯🇵 **例2（CountdownDemo）**

- `for (int i = 5; i >= 1; i--)`：<br><span class="ja-inline">🇯🇵 `for (int i = 5; i >= 1; i--)`：</span>
  - `int i = 5`：初始化，只在循环开始前执行一次。<br><span class="ja-inline">🇯🇵 `int i = 5`：初期化であり、ループ開始前に1回だけ実行されます。</span>
  - `i >= 1`：每轮循环开始前都会判断，为 `true` 才继续执行循环体。<br><span class="ja-inline">🇯🇵 `i >= 1`：毎回のループ開始前に判定され、`true` の場合のみループ本体が実行されます。</span>
  - `i--`：每轮循环体执行完之后自动执行，让 `i` 递减 1。<br><span class="ja-inline">🇯🇵 `i--`：毎回のループ本体の実行後に自動的に実行され、`i` を1減らします。</span>
  - 循环体 `System.out.println(i);` 会依次打印 `5 4 3 2 1`。<br><span class="ja-inline">🇯🇵 ループ本体の `System.out.println(i);` は順に `5 4 3 2 1` を出力します。</span>
- `while (count >= 1)`：结构更简单，只有条件判断。但递减操作 `count--;` 必须自己写在循环体里，如果忘记写，`count` 永远是 5，条件永远为真，就会陷入**死循环**（程序卡住，永远不会结束）。<br><span class="ja-inline">🇯🇵 `while (count >= 1)`：構造はよりシンプルで、条件判定のみです。ただし減算処理 `count--;` は自分でループ本体の中に書く必要があります。書き忘れると `count` は常に5のままとなり、条件は常に真となるため、**無限ループ**（プログラムが止まってしまい、決して終わらない状態）に陥ります。</span>

## 程序运行过程 ／ プログラムの実行の流れ

以 `GradeDemo` 为例：

> 🇯🇵 `GradeDemo` を例にします。

1. JVM 执行到 `int score = 78;`，内存中存入 78。<br><span class="ja-inline">🇯🇵 JVMが `int score = 78;` を実行すると、メモリに78が保存されます。</span>
2. 判断 `score >= 90`：`78 >= 90` 为 `false`，跳过这个分支。<br><span class="ja-inline">🇯🇵 `score >= 90` を判定すると、`78 >= 90` は `false` なので、この分岐はスキップされます。</span>
3. 判断 `score >= 75`：`78 >= 75` 为 `true`，执行 `grade = "良好";`，然后**直接跳过后面所有 `else if` 和 `else`**，继续执行 `if-else` 结构之后的代码。<br><span class="ja-inline">🇯🇵 `score >= 75` を判定すると、`78 >= 75` は `true` なので `grade = "良好";` が実行され、その後**残りの `else if` と `else` はすべてスキップ**され、`if-else` 構造の後のコードへ進みます。</span>
4. 执行 `System.out.println(...)`，打印结果。<br><span class="ja-inline">🇯🇵 `System.out.println(...)` が実行され、結果が出力されます。</span>

输出：
> 🇯🇵 出力：
```
分数：78，等级：良好
```

以 `CountdownDemo` 的 for 循环为例：

> 🇯🇵 `CountdownDemo` の for ループを例にします。

1. `i` 初始化为 `5`。<br><span class="ja-inline">🇯🇵 `i` が `5` に初期化されます。</span>
2. 判断 `i >= 1` 成立 → 打印 `5` → 执行 `i--`，`i` 变为 `4`。<br><span class="ja-inline">🇯🇵 `i >= 1` が成立 → `5` を出力 → `i--` を実行し、`i` は `4` になります。</span>
3. 判断 `i >= 1` 成立 → 打印 `4` → `i` 变为 `3`。<br><span class="ja-inline">🇯🇵 `i >= 1` が成立 → `4` を出力 → `i` は `3` になります。</span>
4. 依次类推，直到打印 `1` 后 `i` 变为 `0`。<br><span class="ja-inline">🇯🇵 以下同様に続き、`1` を出力した後に `i` は `0` になります。</span>
5. 判断 `i >= 1`：`0 >= 1` 为 `false`，循环结束，跳到 `System.out.println("发射！");`。<br><span class="ja-inline">🇯🇵 `i >= 1` を判定すると `0 >= 1` は `false` なので、ループが終了し、`System.out.println("発射！");` へ進みます。</span>

## 常见错误 ／ よくあるエラー

| 现象 ／ 現象 | 原因 ／ 原因 | 解决 ／ 解決方法 |
|---|---|---|
| 程序卡住不动，控制台一直没有输出结束<br><span class="ja-inline">🇯🇵 プログラムが止まったままで、コンソールにいつまでも終了の出力が現れない </span>| `while` 循环体里忘了写让条件趋向 `false` 的语句（比如忘了 `count--`），导致死循环<br><span class="ja-inline">🇯🇵 `while` のループ本体に条件を `false` に近づける文（例えば `count--`）を書き忘れたため、無限ループになっている </span>| 检查循环体，确保有能让条件最终变为 `false` 的操作<br><span class="ja-inline">🇯🇵 ループ本体を確認し、条件を最終的に `false` にできる処理があるか確かめる </span>|
| 用 `=` 代替 `==` 写在 `if` 里，比如 `if (score = 60)`<br><span class="ja-inline">🇯🇵 `if` の中で `==` の代わりに `=` を使ってしまう、例えば `if (score = 60)` </span>| `=` 是赋值，`==` 才是比较，Java 里这样写通常编译不通过（因为 `int` 不能自动转成 `boolean`），但换成 `boolean` 变量时非常容易犯这个错误还不报错<br><span class="ja-inline">🇯🇵 `=` は代入で `==` が比較です。Javaではこう書くと通常コンパイルが通りません（`int` は自動的に `boolean` に変換できないため）が、`boolean` 変数に置き換えるとこのミスをしてもエラーが出ないことがよくあります </span>| 判断相等一律用 `==`，赋值用 `=`，写的时候多看一眼<br><span class="ja-inline">🇯🇵 等しいかどうかの判定には必ず `==` を使い、代入には `=` を使う。書くときによく確認する </span>|
| `else if` 顺序反了导致判断结果不对，比如先判断 `score >= 60` 再判断 `score >= 90`<br><span class="ja-inline">🇯🇵 `else if` の順序が逆になり、判定結果が誤る、例えば先に `score >= 60` を判定してから `score >= 90` を判定する </span>| 一旦命中靠前的条件就不会再往下判断，顺序反了会让本该是"优秀"的分数被判成"及格"<br><span class="ja-inline">🇯🇵 前の条件に一致した時点でそれ以降は判定されないため、順序が逆だと本来「優秀」であるはずの点数が「及格」と判定されてしまう </span>| 多区间判断时按从严格到宽松（或反过来）的顺序排列条件<br><span class="ja-inline">🇯🇵 複数区間の判定は、厳しい方から緩い方へ（またはその逆に）順序よく条件を並べる </span>|
| `for` 循环少些一个分号或者写成两个分号<br><span class="ja-inline">🇯🇵 `for` ループでセミコロンが1つ足りない、または2つ書いてしまう </span>| `for` 的三个部分必须用两个 `;` 隔开，写法固定<br><span class="ja-inline">🇯🇵 `for` の3つの部分は必ず2つの `;` で区切る決まった書き方である </span>| 严格按照 `for (初始化; 条件; 每轮动作)` 的格式书写<br><span class="ja-inline">🇯🇵 `for (初期化; 条件; 毎回の処理)` の形式を厳密に守って書く </span>|

       System.out.println("及格");
   } else if (score >= 90) {
       System.out.println("优秀");
   }

<summary>参考答案 ／ 解答</summary>

1. 能互相替代，二者本质上都是"条件为真就继续执行"。经验规则：次数或范围明确（比如遍历数组、循环固定次数）用 `for`；循环次数依赖运行时才能确定的条件（比如"直到用户输入退出"）用 `while`，这样代码读起来更符合语义。<br><span class="ja-inline">🇯🇵 互いに置き換え可能です。どちらも本質的には「条件が真である限り実行を続ける」ものです。経験則としては、回数や範囲が明確な場合（配列の巡回、固定回数のループなど）は `for` を、実行時にならないと確定しない条件によるループ回数（「ユーザーが終了と入力するまで」など）の場合は `while` を使うと、コードがより意味に沿って読みやすくなります。</span>
2. 输出 `及格`。因为 `if-else if` 结构一旦命中第一个为 `true` 的分支就会执行它并跳过后面所有分支，即使后面的 `score >= 90` 本来也成立，也不会再被判断。<br><span class="ja-inline">🇯🇵 `及格` が出力されます。`if-else if` 構造は最初に `true` となった分岐に一致した時点でそれを実行し、以降の分岐はすべてスキップするためです。後ろの `score >= 90` が本来成立していたとしても、もう判定されません。</span>
