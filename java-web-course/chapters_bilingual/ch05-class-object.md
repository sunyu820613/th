# 第 5 章　类与对象 ／ 第5章　クラスとオブジェクト

## 本章目标 ／ 本章の目標
理解类和对象的关系；能用一个类描述一种业务数据结构（比如学生）；掌握字段、方法、构造方法（无参和多参）以及 `this` 关键字的用法。

> 🇯🇵 クラスとオブジェクトの関係を理解します。1つのクラスで業務データ構造（例えば学生）を表現できるようになります。フィールド、メソッド、コンストラクタ（引数なし・引数ありの両方）、および `this` キーワードの使い方を習得します。

## 一句话理解 ／ 一言で理解する
类是"图纸"，对象是"按图纸造出来的具体产品"——`Student` 这个类描述"学生应该有哪些信息、能做哪些事"，而"小明"、"小红"则是根据这张图纸造出来的一个个具体学生对象。

> 🇯🇵 クラスは「設計図」、オブジェクトは「設計図に基づいて作られた具体的な製品」です——`Student` というクラスは「学生はどんな情報を持ち、何ができるべきか」を記述し、「太郎」「花子」はこの設計図に基づいて作られた個々の具体的な学生オブジェクトです。

## 为什么需要它 ／ なぜ必要なのか
前面几章的数据都是零散的（一个个 `int`、一个个数组），但真实业务里的一个"学生"包含姓名、年龄、成绩等好几项信息，而且这些信息是"绑在一起"的——不能把小明的名字和小红的年龄搭配在一起。类把这些相关的数据（字段）和操作这些数据的行为（方法）打包成一个整体，对象就是这个整体的一份具体实例。这是面向对象编程的起点，也是后面 Controller、Service、Entity 等一切 Java Web 概念的基础。

> 🇯🇵 これまでの章のデータはバラバラでした（1つずつの `int`、1つずつの配列）。しかし実際の業務における1人の「学生」には、氏名・年齢・成績など複数の情報が含まれ、しかもこれらの情報は「一緒に束ねられて」います——太郎の名前と花子の年齢を組み合わせるわけにはいきません。クラスはこれらの関連するデータ（フィールド）と、そのデータを操作する振る舞い（メソッド）を1つのまとまりにパッケージ化し、オブジェクトはそのまとまりの具体的なインスタンスです。これがオブジェクト指向プログラミングの出発点であり、後で学ぶController、Service、Entityなど、あらゆるJava Webの概念の基礎にもなります。

## 核心概念 ／ コアコンセプト

### 5.1 类和对象的关系 ／ クラスとオブジェクトの関係

- **类（Class）**：一种数据类型的定义，描述"这类东西应该有哪些属性（字段）、能做哪些事（方法）"。<br><span class="ja-inline">🇯🇵 **クラス（Class）**：あるデータ型の定義であり、「この種類のものはどんな属性（フィールド）を持ち、何ができるか（メソッド）」を記述します。</span>
- **对象（Object）**：根据类创建出来的具体实例，也叫"实例（Instance）"。创建对象的过程叫"实例化"，用关键字 `new`。<br><span class="ja-inline">🇯🇵 **オブジェクト（Object）**：クラスに基づいて作成された具体的な実体で、「インスタンス（Instance）」とも呼ばれます。オブジェクトを作成する過程を「インスタンス化」と呼び、キーワード `new` を使います。</span>
- 一个类可以创建任意多个对象，每个对象的字段值可以各不相同，但它们的"结构"（有哪些字段、有哪些方法）是一样的。<br><span class="ja-inline">🇯🇵 1つのクラスからは任意の数のオブジェクトを作成でき、各オブジェクトのフィールドの値はそれぞれ異なっていても構いませんが、それらの「構造」（どんなフィールドがあり、どんなメソッドがあるか）は同じです。</span>

### 5.2 字段（Field） ／ フィールド（Field）

字段是类里声明的变量，用来描述这类对象"有什么"：

> 🇯🇵 フィールドはクラス内で宣言される変数で、その種類のオブジェクトが「何を持っているか」を記述します。

```java
public class Student {
    String name;
    int age;
    double score;
}
```

`name`、`age`、`score` 就是 `Student` 类的字段。每个 `Student` 对象都会拥有这三个字段各自的一份拷贝——小明的 `name` 是 "小明"，小红的 `name` 是 "小红"，互不影响。

> 🇯🇵 `name`、`age`、`score` が `Student` クラスのフィールドです。各 `Student` オブジェクトはこの3つのフィールドそれぞれの独立したコピーを持ちます——太郎の `name` は「太郎」、花子の `name` は「花子」というように、互いに影響しません。

### 5.3 方法（Method） ／ メソッド（Method）

方法描述这类对象"能做什么"：

> 🇯🇵 メソッドはその種類のオブジェクトが「何ができるか」を記述します。

```java
public class Student {
    String name;
    int age;
    double score;

    void printInfo() {
        System.out.println(name + "，" + age + "岁，成绩" + score);
    }
}
```

`printInfo()` 就是一个方法，调用它可以打印这个具体学生对象的信息。

> 🇯🇵 `printInfo()` はメソッドの1つであり、これを呼び出すとその具体的な学生オブジェクトの情報を出力できます。

### 5.4 构造方法（Constructor） ／ コンストラクタ（Constructor）

**构造方法**是一个特殊的方法，专门在 `new` 创建对象的那一刻自动执行，通常用来给字段赋初始值。它有三个特点：

> 🇯🇵 **コンストラクタ**は特殊なメソッドで、`new` でオブジェクトを作成する瞬間に自動的に実行され、通常はフィールドに初期値を設定するために使われます。次の3つの特徴があります。

1. 方法名必须和类名完全一致；<br><span class="ja-inline">🇯🇵 メソッド名はクラス名と完全に一致させなければならない。</span>
2. 没有返回值类型，连 `void` 都不写；<br><span class="ja-inline">🇯🇵 戻り値の型を持たない。`void` すら書かない。</span>
3. 如果你一个构造方法都不写，Java 会自动提供一个"什么都不做"的**无参构造方法**；但只要你自己写了任意一个构造方法，这个自动提供的无参构造就不再存在，如果还想保留无参构造，需要自己显式写出来。<br><span class="ja-inline">🇯🇵 もしコンストラクタを1つも書かなければ、Javaは自動的に「何もしない」**引数なしコンストラクタ**を提供する。しかし自分で任意のコンストラクタを1つでも書くと、この自動提供される引数なしコンストラクタは存在しなくなる。引数なしコンストラクタを残したい場合は、自分で明示的に書く必要がある。</span>

```java
public class Student {
    String name;
    int age;
    double score;

    // 无参构造方法
    public Student() {
    }

    // 多参构造方法，创建对象时直接把值传进来
    public Student(String name, int age, double score) {
        this.name = name;
        this.age = age;
        this.score = score;
    }
}
```

### 5.5 this 关键字 ／ this キーワード

`this` 指的是"当前这个对象自己"。最常见的用法是在构造方法或普通方法里，**当参数名和字段名相同时**，用 `this.字段名` 明确表示"我说的是这个对象自己的字段"，而不是参数：

> 🇯🇵 `this` は「現在のこのオブジェクト自身」を指します。最もよく使われるのは、コンストラクタや通常のメソッドにおいて**引数名とフィールド名が同じ場合**に、`this.フィールド名` と書いて「これはこのオブジェクト自身のフィールドを指している」ことを明示し、引数ではないことを示す用法です。

```java
public Student(String name, int age, double score) {
    this.name = name;   // 左边 this.name 是字段，右边 name 是参数
    this.age = age;
    this.score = score;
}
```

如果没有 `this`，写成 `name = name;`，Java 会认为这是"参数自己赋值给自己"，字段根本没有被赋值成功——这是初学者极易忽略的细节。

> 🇯🇵 もし `this` がなく `name = name;` と書いてしまうと、Javaはこれを「引数が自分自身に代入する」ものと解釈し、フィールドには実際には値が代入されません——これは初心者が非常に見落としやすい細部です。

## 最小示例 ／ 最小限のサンプル

`Student.java`
```java
public class Student {
    String name;
    int age;
    double score;

    // 无参构造方法：什么都不做，字段会是默认值（null / 0 / 0.0）
    public Student() {
    }

    // 多参构造方法：创建对象时直接初始化好所有字段
    public Student(String name, int age, double score) {
        this.name = name;
        this.age = age;
        this.score = score;
    }

    void printInfo() {
        System.out.println(name + "，" + age + "岁，成绩" + score);
    }
}
```

`StudentDemo.java`
```java
public class StudentDemo {
    public static void main(String[] args) {
        // 用多参构造方法创建对象，一次性初始化好所有字段
        Student stu1 = new Student("小明", 18, 88.5);
        stu1.printInfo();

        // 用无参构造方法创建对象，再手动一个个赋值
        Student stu2 = new Student();
        stu2.name = "小红";
        stu2.age = 19;
        stu2.score = 92.0;
        stu2.printInfo();
    }
}
```

## 代码逐行解释 ／ コードの行ごとの解説

- `String name; int age; double score;`：三个字段，注意它们没有像局部变量那样立即赋值——字段如果不赋值，会有默认值（`String` 等对象类型默认是 `null`，`int` 默认是 `0`，`double` 默认是 `0.0`）。<br><span class="ja-inline">🇯🇵 `String name; int age; double score;`：3つのフィールドです。ローカル変数のように即座に値を代入していない点に注意してください——フィールドは値を代入しなければデフォルト値になります（`String` などのオブジェクト型のデフォルトは `null`、`int` のデフォルトは `0`、`double` のデフォルトは `0.0` です）。</span>
- `public Student() { }`：无参构造方法，方法体为空，创建出来的对象所有字段都是默认值。<br><span class="ja-inline">🇯🇵 `public Student() { }`：引数なしコンストラクタです。メソッド本体は空で、作成されるオブジェクトのすべてのフィールドはデフォルト値になります。</span>
- `public Student(String name, int age, double score)`：多参构造方法，注意参数名和字段名故意写成一样（这是常见习惯，方便阅读），所以方法体内必须用 `this.` 区分。<br><span class="ja-inline">🇯🇵 `public Student(String name, int age, double score)`：引数ありコンストラクタです。引数名とフィールド名がわざと同じにしてある点に注意してください（これはよくある習慣で、読みやすくするためです）。そのためメソッド本体では `this.` で区別しなければなりません。</span>
- `this.name = name;`：`this.name` 指"当前正在创建的这个对象的 name 字段"，等号右边的 `name` 指"传进来的参数"。<br><span class="ja-inline">🇯🇵 `this.name = name;`：`this.name` は「現在作成中のこのオブジェクトの name フィールド」を指し、等号右側の `name` は「渡されてきた引数」を指します。</span>
- `Student stu1 = new Student("小明", 18, 88.5);`：`new Student(...)` 触发多参构造方法执行，把三个参数分别赋给 `stu1` 的三个字段；`Student stu1 = ...` 把创建好的对象交给变量 `stu1` 保管。<br><span class="ja-inline">🇯🇵 `Student stu1 = new Student("小明", 18, 88.5);`：`new Student(...)` が引数ありコンストラクタの実行をトリガーし、3つの引数をそれぞれ `stu1` の3つのフィールドに代入します。`Student stu1 = ...` は作成されたオブジェクトを変数 `stu1` に保管させます。</span>
- `Student stu2 = new Student();`：触发无参构造方法，`stu2` 的三个字段暂时都是默认值。<br><span class="ja-inline">🇯🇵 `Student stu2 = new Student();`：引数なしコンストラクタをトリガーし、`stu2` の3つのフィールドは一旦すべてデフォルト値になります。</span>
- `stu2.name = "小红";`：通过"对象.字段名"的方式，在对象创建之后再单独给字段赋值。<br><span class="ja-inline">🇯🇵 `stu2.name = "小红";`：「オブジェクト.フィールド名」という方式で、オブジェクト作成後に個別にフィールドへ値を代入します。</span>
- `stu1.printInfo();`：调用 `stu1` 这个具体对象的方法，方法体里的 `name`、`age`、`score` 用的就是 `stu1` 自己的那份数据。<br><span class="ja-inline">🇯🇵 `stu1.printInfo();`：`stu1` という具体的なオブジェクトのメソッドを呼び出します。メソッド本体内の `name`、`age`、`score` は `stu1` 自身のデータを使います。</span>

## 程序运行过程 ／ プログラムの実行の流れ

1. JVM 执行 `new Student("小明", 18, 88.5)`：先在内存中开辟一块空间用来存放这个新对象的三个字段，然后调用匹配参数个数和类型的那个构造方法（这里是三参构造），把三个字面量依次赋给 `name`、`age`、`score`。<br><span class="ja-inline">🇯🇵 JVMが `new Student("小明", 18, 88.5)` を実行します。まずメモリ上にこの新しいオブジェクトの3つのフィールドを格納する領域を確保し、次に引数の個数と型に一致するコンストラクタ（ここでは3引数のコンストラクタ）を呼び出し、3つのリテラルを順に `name`、`age`、`score` に代入します。</span>
2. 构造方法执行完毕，这个新对象的引用（可以理解成"这块内存的地址"）被赋值给变量 `stu1`。<br><span class="ja-inline">🇯🇵 コンストラクタの実行が終わると、この新しいオブジェクトの参照（「このメモリ領域のアドレス」と理解してよい）が変数 `stu1` に代入されます。</span>
3. `stu1.printInfo();`：JVM 找到 `stu1` 指向的那个具体对象，执行它的 `printInfo` 方法，方法体里访问的 `name/age/score` 就是 `stu1` 自己的字段值。<br><span class="ja-inline">🇯🇵 `stu1.printInfo();`：JVMは `stu1` が指し示す具体的なオブジェクトを見つけ、その `printInfo` メソッドを実行します。メソッド本体でアクセスする `name/age/score` は `stu1` 自身のフィールド値です。</span>
4. `new Student()` 同理，但因为是无参构造，三个字段暂时是默认值，随后三行 `stu2.xxx = ...` 分别把值补上。<br><span class="ja-inline">🇯🇵 `new Student()` も同様ですが、引数なしコンストラクタであるため3つのフィールドは一旦デフォルト値になり、その後の3行の `stu2.xxx = ...` でそれぞれ値が補われます。</span>
5. `stu2.printInfo();` 打印出 `stu2` 自己的字段值，和 `stu1` 完全独立、互不影响。<br><span class="ja-inline">🇯🇵 `stu2.printInfo();` は `stu2` 自身のフィールド値を出力し、`stu1` とは完全に独立していて互いに影響しません。</span>

输出：
> 🇯🇵 出力：
```
小明，18岁，成绩88.5
小红，19岁，成绩92.0
```

## 动手练习 ／ 演習

1. 参照 `Student` 类，自己写一个 `Book` 类，包含字段 `title`（书名）、`price`（价格）、`stock`（库存），写一个无参构造和一个三参构造。<br><span class="ja-inline">🇯🇵 `Student` クラスを参考に、`title`（書名）、`price`（価格）、`stock`（在庫）というフィールドを持つ `Book` クラスを自分で書き、引数なしコンストラクタと3引数コンストラクタをそれぞれ1つ書いてみましょう。</span>
2. 给 `Student` 类新增一个方法 `boolean isPass()`，判断这个学生的 `score` 是否及格（大于等于 60），并在 `main` 方法里测试。<br><span class="ja-inline">🇯🇵 `Student` クラスに `boolean isPass()` というメソッドを追加し、その学生の `score` が合格（60以上）かどうかを判定して、`main` メソッドでテストしてみましょう。</span>

## 小测验 ／ 小テスト

1. 类和对象分别是什么？打个比方说明二者的关系。<br><span class="ja-inline">🇯🇵 クラスとオブジェクトはそれぞれ何ですか？例えを使って両者の関係を説明してください。</span>
2. 为什么构造方法里经常需要写 `this.name = name;` 而不是直接写 `name = name;`？<br><span class="ja-inline">🇯🇵 なぜコンストラクタでは `name = name;` ではなく `this.name = name;` と書く必要がよくあるのですか？</span>
3. 如果一个类自己写了一个带参数的构造方法，但没写无参构造方法，`new 类名()` 会发生什么？<br><span class="ja-inline">🇯🇵 もしあるクラスが引数ありコンストラクタを自分で書いたが、引数なしコンストラクタを書かなかった場合、`new クラス名()` を実行するとどうなりますか？</span>

<details>
<summary>参考答案 ／ 解答</summary>

1. 类是"图纸"（数据结构的定义），对象是"根据图纸造出来的具体实例"。比如 `Student` 类定义了"学生应该有姓名、年龄、成绩"，而"小明"这个具体的人就是一个 `Student` 对象。<br><span class="ja-inline">🇯🇵 クラスは「設計図」（データ構造の定義）であり、オブジェクトは「設計図に基づいて作られた具体的な実体」です。例えば `Student` クラスは「学生は氏名・年齢・成績を持つべきである」と定義しており、「太郎」という具体的な人物が1つの `Student` オブジェクトです。</span>
2. 因为参数名和字段名相同时，直接写 `name = name;` 会被理解成"参数自己赋值给自己"，字段根本没有被赋值。加上 `this.` 明确表示左边是"当前对象的字段"。<br><span class="ja-inline">🇯🇵 引数名とフィールド名が同じ場合、直接 `name = name;` と書くと「引数が自分自身に代入する」と解釈され、フィールドには全く値が代入されないからです。`this.` を付けることで、左辺が「現在のオブジェクトのフィールド」であることを明示します。</span>
3. 会编译报错，提示找不到无参构造方法——因为只要类里自定义了任意一个构造方法，Java 就不会再提供默认的无参构造。<br><span class="ja-inline">🇯🇵 コンパイルエラーになり、引数なしコンストラクタが見つからないと表示されます——クラス内で任意のコンストラクタを1つでも自分で定義すると、Javaはデフォルトの引数なしコンストラクタをもう提供しないからです。</span>
