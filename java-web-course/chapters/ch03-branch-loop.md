# 第 3 章　分支与循环

## 本章目标
掌握 `if / else if / else` 做条件判断，掌握 `for` 和 `while` 做重复执行；能根据场景判断该用哪种循环。

## 一句话理解
分支是"根据条件走不同的路"，循环是"把同一段代码反复执行很多遍"——它们是程序具备"判断力"和"耐力"的开始。

## 为什么需要它
如果程序只能从上到下顺序执行，那它顶多算个计算器：算一次就完事。而现实业务几乎都需要"判断"（比如成绩及格还是不及格）和"重复"（比如把 100 个用户的信息都打印一遍）。有了分支和循环，程序才第一次具备处理"真实业务逻辑"的能力。

## 核心概念

### 3.1 分支：if / else if / else

```
if (条件1) {
    // 条件1 成立时执行
} else if (条件2) {
    // 条件1 不成立、条件2 成立时执行
} else {
    // 前面条件都不成立时执行
}
```

- 条件必须是一个 `boolean` 表达式（结果是 `true` 或 `false`），不能像某些语言那样直接写 `if (1)`。
- `else if` 可以写多个，`else` 最多一个且必须放最后，也可以不写 `else`。
- 分支是"从上到下，命中一个就跳出，后面的都不再判断"。

### 3.2 循环：for 和 while

`for` 循环，语法上把"初始化、判断条件、每轮之后的动作"写在一行里：

```
for (初始化; 条件; 每轮结束后执行) {
    // 循环体
}
```

`while` 循环，只关心"条件为真就继续"：

```
while (条件) {
    // 循环体
}
```

还有一种 `do-while`，特点是"先执行一次，再判断要不要继续"，本教程后面不常用，这里只作了解：

```
do {
    // 至少执行一次
} while (条件);
```

### 3.3 到底该用 for 还是 while？

一句话判断标准：**明确知道要循环几次（或者有一个明显的计数器），用 `for`；只知道"满足某个条件就继续，不知道具体几次"，用 `while`。**

| 场景 | 特点 | 该用 |
|---|---|---|
| 打印 1 到 100 | 次数从一开始就是确定的（100 次） | `for` |
| 遍历数组/集合里的每个元素 | 元素个数是确定的 | `for` |
| 倒计时"从 10 数到发射" | 每次减 1，直到某个值，条件驱动更自然 | `for` 或 `while` 都可以，这里两种都演示 |
| 反复读取用户输入，直到用户输入"退出" | 不知道用户会输入几次 | `while` |
| 库存不断被扣减，直到库存为 0 | 每轮扣减的数量可能不固定，次数不确定 | `while` |

记住这个经验规则就够用了：**次数确定用 for，条件不确定用 while**。两者本质上可以互相改写，选择哪个只是让代码读起来更自然。

## 图解

```
if / else if / else 的执行路径（只走一条）：

           ┌───条件1 true───▶ 执行分支1 ──┐
开始 ──────┤                              ├──▶ 结束
           ├───条件2 true───▶ 执行分支2 ──┤
           │                              │
           └───都不成立────▶ 执行 else ───┘

for 循环的执行顺序：

初始化 ──▶ 判断条件 ──true──▶ 执行循环体 ──▶ 执行"每轮结束动作" ──┐
              ▲                                                  │
              └──────────────────────────────────────────────────┘
              │
             false
              ▼
            跳出循环
```

## 最小示例

### 示例一：成绩判定（分支）

`GradeDemo.java`
```java
public class GradeDemo {
    public static void main(String[] args) {
        int score = 78;
        String grade;

        if (score >= 90) {
            grade = "优秀";
        } else if (score >= 75) {
            grade = "良好";
        } else if (score >= 60) {
            grade = "及格";
        } else {
            grade = "不及格";
        }

        System.out.println("分数：" + score + "，等级：" + grade);
    }
}
```

### 示例二：倒计时（for 和 while 两种写法对比）

`CountdownDemo.java`
```java
public class CountdownDemo {
    public static void main(String[] args) {
        // 写法一：用 for，因为"从 5 数到 1"次数是确定的
        System.out.println("---- for 版本 ----");
        for (int i = 5; i >= 1; i--) {
            System.out.println(i);
        }
        System.out.println("发射！");

        // 写法二：用 while，效果完全一样，只是换了一种表达方式
        System.out.println("---- while 版本 ----");
        int count = 5;
        while (count >= 1) {
            System.out.println(count);
            count--;
        }
        System.out.println("发射！");
    }
}
```

## 代码逐行解释

**示例一（GradeDemo）**

- `if (score >= 90)`：先判断是否达到"优秀"的门槛。
- `else if (score >= 75)`：只有在第一条不成立时才会走到这里判断——所以这里不需要再写 `score < 90 && score >= 75`，因为能走到这一步就已经说明 `score < 90` 了。
- `else if (score >= 60)`：同理，只需要判断下限。
- `else`：前面所有条件都不满足，兜底为"不及格"。
- 这里体现了一个重要习惯：**多个区间判断时，从高到低（或从低到高）依次排列，配合 `else if`，避免逻辑重复和遗漏**。

**示例二（CountdownDemo）**

- `for (int i = 5; i >= 1; i--)`：
  - `int i = 5`：初始化，只在循环开始前执行一次。
  - `i >= 1`：每轮循环开始前都会判断，为 `true` 才继续执行循环体。
  - `i--`：每轮循环体执行完之后自动执行，让 `i` 递减 1。
  - 循环体 `System.out.println(i);` 会依次打印 `5 4 3 2 1`。
- `while (count >= 1)`：结构更简单，只有条件判断。但递减操作 `count--;` 必须自己写在循环体里，如果忘记写，`count` 永远是 5，条件永远为真，就会陷入**死循环**（程序卡住，永远不会结束）。

## 程序运行过程

以 `GradeDemo` 为例：

1. JVM 执行到 `int score = 78;`，内存中存入 78。
2. 判断 `score >= 90`：`78 >= 90` 为 `false`，跳过这个分支。
3. 判断 `score >= 75`：`78 >= 75` 为 `true`，执行 `grade = "良好";`，然后**直接跳过后面所有 `else if` 和 `else`**，继续执行 `if-else` 结构之后的代码。
4. 执行 `System.out.println(...)`，打印结果。

输出：
```
分数：78，等级：良好
```

以 `CountdownDemo` 的 for 循环为例：

1. `i` 初始化为 `5`。
2. 判断 `i >= 1` 成立 → 打印 `5` → 执行 `i--`，`i` 变为 `4`。
3. 判断 `i >= 1` 成立 → 打印 `4` → `i` 变为 `3`。
4. 依次类推，直到打印 `1` 后 `i` 变为 `0`。
5. 判断 `i >= 1`：`0 >= 1` 为 `false`，循环结束，跳到 `System.out.println("发射！");`。

## 常见错误

| 现象 | 原因 | 解决 |
|---|---|---|
| 程序卡住不动，控制台一直没有输出结束 | `while` 循环体里忘了写让条件趋向 `false` 的语句（比如忘了 `count--`），导致死循环 | 检查循环体，确保有能让条件最终变为 `false` 的操作 |
| 用 `=` 代替 `==` 写在 `if` 里，比如 `if (score = 60)` | `=` 是赋值，`==` 才是比较，Java 里这样写通常编译不通过（因为 `int` 不能自动转成 `boolean`），但换成 `boolean` 变量时非常容易犯这个错误还不报错 | 判断相等一律用 `==`，赋值用 `=`，写的时候多看一眼 |
| `else if` 顺序反了导致判断结果不对，比如先判断 `score >= 60` 再判断 `score >= 90` | 一旦命中靠前的条件就不会再往下判断，顺序反了会让本该是"优秀"的分数被判成"及格" | 多区间判断时按从严格到宽松（或反过来）的顺序排列条件 |
| `for` 循环少些一个分号或者写成两个分号 | `for` 的三个部分必须用两个 `;` 隔开，写法固定 | 严格按照 `for (初始化; 条件; 每轮动作)` 的格式书写 |

## 小测验

1. `for` 和 `while` 在功能上能互相替代吗？该怎么选择使用哪一个？
2. 下面这段代码会输出什么？为什么？
   ```java
   int score = 90;
   if (score >= 60) {
       System.out.println("及格");
   } else if (score >= 90) {
       System.out.println("优秀");
   }
   ```
3. 写一个死循环的例子，并说明为什么它是死循环。

<details>
<summary>参考答案</summary>

1. 能互相替代，二者本质上都是"条件为真就继续执行"。经验规则：次数或范围明确（比如遍历数组、循环固定次数）用 `for`；循环次数依赖运行时才能确定的条件（比如"直到用户输入退出"）用 `while`，这样代码读起来更符合语义。
2. 输出 `及格`。因为 `if-else if` 结构一旦命中第一个为 `true` 的分支就会执行它并跳过后面所有分支，即使后面的 `score >= 90` 本来也成立，也不会再被判断。
3. 例如：
   ```java
   int i = 0;
   while (i < 5) {
       System.out.println(i);
       // 忘记写 i++;
   }
   ```
   因为 `i` 永远是 `0`，条件 `i < 5` 永远为 `true`，循环永远不会结束。
</details>
